💡 Temuan Kunci Riset Tata Kelola Data Bookmark

1. Struktur Netscape HTML loose-parsing

Berkas bookmark modern mengabaikan tag penutup </DT> dan </p>. Parser backend harus menggunakan metode pencarian pohon rekursif berbasis tumpukan (stack DOM parsing) agar hierarki folder tidak runtuh.

2. Dekopling Favicon Base64

Atribut ICON="data:image/png;base64,..." memperbesar ukuran database jika disimpan secara langsung. Strategi terbaik adalah mendekode gambar biner dan menyimpannya ke Object Storage (S3/MinIO) dengan rujukan string path.

3. Parameter Tracking & Hash Unik

Banyak URL referensi mengandung tracking seperti ?src=startpage atau utm_campaign. Menghapus parameter ini menghasilkan URL kanonikal murni untuk deteksi duplikat presisi tinggi dengan SHA-256.

import hashlib
from urllib.parse import urlparse, parse_qs, urlencode, urlunparse

def canonicalize_bookmark_url(raw_url: str):
    """
    Eksekusi normalisasi URL untuk menghilangkan variasi berlebih
    dan menghasilkan hash SHA-256 presisi tinggi.
    """
    parsed = urlparse(raw_url.strip())
    
    # Deteksi Protokol Internal Browser
    if parsed.scheme in ['chrome', 'edge', 'about', 'file']:
        return raw_url, True, hashlib.sha256(raw_url.encode()).hexdigest()
        
    scheme = parsed.scheme.lower()
    netloc = parsed.netloc.lower()
    
    # Stripping port standar
    if netloc.endswith(':80') and scheme == 'http': netloc = netloc[:-3]
    elif netloc.endswith(':443') and scheme == 'https': netloc = netloc[:-4]
    
    # Stripping prefix www berlebih
    if netloc.startswith('www.'): netloc = netloc[4:]
    
    # Stripping tracking parameters
    query_params = parse_qs(parsed.query)
    ignored_keys = {'utm_source', 'utm_medium', 'utm_campaign', 'fbclid', 'gclid', 'ref', 'affiliate_id', 'src'}
    filtered_params = {k: v for k, v in query_params.items() if k.lower() not in ignored_keys}
    
    sorted_query = urlencode(sorted(filtered_params.items()), doseq=True)
    path = parsed.path.rstrip('/')
    
    # Rekonstruksi URL Kanonikal murni (tanpa fragment #)
    canonical_url = urlunparse((scheme, netloc, path, '', sorted_query, ''))
    url_hash = hashlib.sha256(canonical_url.encode('utf-8')).hexdigest()
    
    return canonical_url, False, url_hash
